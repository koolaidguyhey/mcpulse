What does “download” mean for each loader?

Vanilla, Paper, Purpur, Folia, and Fabric provide a runnable server JAR or launcher. Forge and NeoForge use installer JARs that generate the server files when you run their documented server-install command. MC Pulse labels installers clearly instead of pretending they are final server JARs.
